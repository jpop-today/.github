# jpop.today

한국 노래방에서 부를 JPOP를 찾는 사람을 위한 노래 번호 사이트입니다. 한글·일본어 곡명, 가수, TJ·금영 번호로 검색하고 마음에 드는 곡을 저장하세요.

[사이트 방문](https://jpop.today) · [새 앱 미리보기](https://jpoptoday-preview.pages.dev) · [개발 진행](https://github.com/jpop-today/docs/blob/main/operations/status.md)

기존 운영 사이트를 유지하면서 조직 저장소에서 새 앱을 개발하고 있습니다. 미리보기의 관측 번호와 공식 확인 번호를 구분하며, 기존 곡 주소와 즐겨찾기를 보존합니다.

매일 오전 9시(한국 시간) 개발 관리자가 세 하위 에이전트의 작업을 조정합니다. 검증된 개선과 릴리스 기록을 남기며, 신뢰할 수 있는 데이터·자체 콘텐츠·운영 품질을 갖춰 Google AdSense 심사를 준비합니다. 실제 승인 상태는 운영 기록으로 확인합니다.
